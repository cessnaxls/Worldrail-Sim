# Asset sources

Recommended free sources for production replacement assets:

- Kenney Train Kit (CC0), OpenGameArt: https://opengameart.org/content/train-kit
  - almost 50 optimized train/track models; CC0.
- Poly Haven (CC0): https://polyhaven.com/
  - PBR concrete, asphalt, HDRIs and models.

For a 2021 iPad, convert models to glTF/GLB, merge static scenery, use <=1K textures for common materials, KTX2/Basis texture compression, and Draco/Meshopt geometry compression. Do not ship the original 8K texture downloads.
