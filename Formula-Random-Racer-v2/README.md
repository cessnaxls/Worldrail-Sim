# Formula Random v2
Complete rebuild of the first prototype.

This build uses a self-contained pseudo-3D road renderer rather than external 3D libraries, so it has no CDN/WebGL-engine dependency.
Features: procedural closed road circuits, gentle elevation, 29 AI opponents, random 1–30 grid position, iOS device tilt steering with permission request, touch steering fallback, touch throttle/brake, automatic or manual no-clutch paddles, and race HUD.

Deploy to Render with the included render.yaml.
