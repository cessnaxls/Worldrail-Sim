# Browsable 3D Asset Library v1

Assets:
- Boeing 737-900
- CRJ200
- CRJ900
- Chevrolet Tahoe
- Toyota Corolla

This is a zero-dependency WebGL browser library intended for iPad. Each asset is generated from reusable game geometry and rendered in a touch-orbit viewer.

Important: these are original low-poly reference/game models, not manufacturer CAD or copied commercial models. They are intended as a foundation for the open-world engine and can be refined into higher-detail UV-mapped assets later.
